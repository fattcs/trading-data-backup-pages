隱私權政策

Trading Data Backup

最後更新：2026 年 9 月 27 日

適用範圍

本工具是供專案擁有者個人使用的本機備份程式，透過 Google Drive API 將擁有者選定的本機檔案備份到擁有者自己的 Google Drive。

存取的 Google 資料

本工具在擁有者明確授權後，得建立資料夾、上傳檔案、讀取檔案中繼資料、比較檔案，以及在執行鏡像同步時更新或刪除目標檔案。權限只用於執行擁有者設定的備份與同步工作。

資料的使用、儲存與分享

  • 檔案由擁有者的電腦直接傳輸到擁有者的 Google Drive。
  • OAuth 憑證只儲存在擁有者的本機電腦，不會提交到原始碼儲存庫。
  • 本工具不販售、不出租，也不向第三方分享 Google 使用者資料。
  • 本工具沒有由專案擁有者營運的外部資料收集伺服器。

資料保留與刪除

備份檔案會保留在擁有者的 Google Drive，直到擁有者自行刪除或依同步規則移除。擁有者可以隨時在 Google 帳戶的第三方存取權設定中撤銷授權，並刪除本機保存的 OAuth 憑證。

安全措施

本機 OAuth 設定檔僅開放給設定者、系統管理員及排程所使用的 Windows 系統帳戶，且不包含在雲端備份或 Git 版本控制中。

聯絡方式

如對本政策有疑問，請透過 專案擁有者的 GitHub 頁面聯絡，或使用 Google OAuth 同意畫面所列的支援電子郵件。
